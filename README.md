## 📖 About

**Hearo for PC** brings the ultimate co-watching experience directly to your desktop. Whether you're hosting a movie night or catching a live stream with friends across the globe, Hearo keeps playback synchronized down to the millisecond while letting you talk and react together in real time.

> **Note:** This repository hosts official desktop builds, release changelogs, and the public issue tracker for **Hearo - Watch Together**. The application source code is closed-source.

---

## ✨ Key Features

- **Frame-Accurate Sync Playback:** Watch content together from major streaming platforms and web sources without manual countdowns.
- **Built-in Low-Latency Voice & Text Chat:** Talk naturally with your watch party without needing third-party voice apps running in the background.
- **Instant Room Invites:** Create a private watch party and invite friends with a single shareable link.
- **Cross-Platform Party Support:** Seamlessly join rooms with friends using Hearo on Windows, macOS, iOS, and Android.
- **Desktop Performance & Audio Controls:** Individual volume sliders for party members, push-to-talk options, and hardware-accelerated video playback.

## 📥 Download & Installation

1. Go to the **[Releases](../../releases)** page of this repository.
2. Download the latest installer for your operating system:
   - **Windows:** `Hearo-Setup-x64.exe` (Windows 10/11 64-bit)
   - **macOS:** `Hearo-Universal.dmg` (Apple Silicon & Intel)
3. Run the installer and follow the on-screen setup instructions.
4. Sign in or create an account to start hosting or joining watch parties.
